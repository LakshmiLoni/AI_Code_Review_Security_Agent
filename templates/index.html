Supported Vulnerability Checks

  • 🔴 SQL Injection (CWE-89): String interpolation in query builders.
  • 🔴 Command Injection (CWE-78): Subshell execution with shell metacharacters.
  • 🔴 Dynamic Code Execution (CWE-95): Unsafe eval() / exec() calls.
  • 🔴 Insecure Deserialization (CWE-502): Python pickle & Java ObjectInputStream.
  • 🟠 Hardcoded Secrets (CWE-798): AWS keys, database URIs, API tokens.
  • 🟡 Weak Cryptography (CWE-327): Deprecated MD5, SHA-1, ECB cipher modes.
  • 🟡 Predictable PRNG (CWE-338): Insecure random for auth/session tokens.
