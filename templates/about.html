About This Project

Technical Architecture, Methodology, and Academic Rationale for College Project Review.

1. Problem Statement & Motivation

Modern software development cycles require rapid code releases, frequently resulting in unreviewed code entering production. Traditional manual code review is slow and error-prone, while enterprise SAST scanners often produce hundreds of opaque alerts without actionable, context-aware remediations.

This project implements an intelligent, explainable Multi-Agent AI Code Review and Security Analysis Agent that combines Abstract Syntax Tree (AST) parsing with an authoritative local Retrieval-Augmented Generation (RAG) cybersecurity knowledge base.

2. Core System Architecture

Code Parser: Converts Python source code into Python AST nodes (ast.parse) and extracts tokenized structures for Java, measuring function lines, branches, and parameters.
Multi-Agent System:
  • Quality Agent: Inspects maintainability, complexity, naming, and error handling.
  • Security Agent: Detects OWASP Top 10 vulnerabilities (SQLi, Command Injection, hardcoded secrets, weak crypto).
  • Remediation Agent: Produces safe side-by-side corrected code and developer guidance.
  • Summary Agent: Computes risk metrics, severity breakdowns, and remaining risk assessments.
RAG Knowledge Base: Over 1,900 lines of rigorous educational content indexed into ChromaDB / scikit-learn TF-IDF vector space for semantic source attribution.
Offline First: Can start and function completely without cloud API credentials using local heuristic synthesis.

3. Technology Stack

Backend Framework:Python 3.11 & Flask 3.1
Static Code Parsing:Python Abstract Syntax Tree (AST), Regular Expressions
Database:SQLite with parameterized queries and foreign keys
RAG & Retrieval:ChromaDB with scikit-learn TF-IDF + Cosine Similarity fallback
Generative AI:Google Gemini API (via modern google-genai SDK)
Frontend:Jinja2, HTML5, CSS3, JavaScript, Chart.js
Testing:pytest & python unittest suite
